I need a standalone Sampling Module that spans field → transport → buying station → warehouse → processing.
Let’s design this properly so it integrates with Our new Commodity Management layer.

NEW MODULE: Sampling & Sample Management
This becomes a cross-cutting module (like Compliance), not just a step.

1. Core Concept
Sampling is not one event—it’s a chain of samples across stages:
Sampling Points:
1.	Field (pre-bulking / farm level)
2.	Pre-offload (truck arrival)
3.	Post-offload (buying station QC)
4.	Warehouse intake
5.	Processing (pre & post process)
6.	Export / final QA
 Each sample must be:
•	Traceable
•	Comparable
•	Versioned
•	Linked to commodity + stage

2. Data Model (Core Tables)
2.1 Sample Master
Table: Sample
•	SampleID
•	SampleCode (auto-generated QR/barcode)
•	CommodityTypeID
•	SampleStage
(Field / Pre-Offload / Post-Offload / Warehouse / Processing / Export)
•	ReferenceType
(Farmer / Batch / Lot / SiloBatch / Container)
•	ReferenceID
•	SampleMethod (grab / composite / incremental)
•	CollectedBy (UserID)
•	CollectionDateTime
•	GPSLocation
•	Status (Pending / Tested / Approved / Rejected)
•	ParentSampleID (for split/retest scenarios)

2.2 Sample Details (Physical)
Table: SampleDetails
•	SampleID
•	Weight
•	NumberOfSubSamples
•	ContainerType
•	SealNumber
•	StorageLocation (lab, fridge, shelf)
•	RetentionPeriod

2.3 Sample Test Results
Table: SampleTest
•	TestID
•	SampleID
•	Parameter (Moisture, Defects, etc.)
•	Value
•	Unit
•	MethodUsed
•	TestedBy
•	TestDate
•	IsOutOfRange (auto)

2.4 Sampling Plan (VERY IMPORTANT)
Table: SamplingPlan
•	PlanID
•	CommodityTypeID
•	Stage
•	SamplingMethod
•	FrequencyRule
(per batch / per X kg / per truck)
•	MinSamples
•	CompositeAllowed (yes/no)
•	Mandatory (yes/no)

2.5 Sample Chain of Custody
Table: SampleMovement
•	MovementID
•	SampleID
•	FromLocation
•	ToLocation
•	MovedBy
•	Timestamp
•	ConditionNotes

5. Sampling Workflows

Workflow 1: Buying Station

2.	Pre-offload sample created
3.	Offloading
4.	Post-offload sample created
5.	Lab testing
6.	Grade determined

Workflow 2: Warehouse Intake
1.	Lot arrives
2.	Intake sample taken
3.	Compare vs buying station sample

Workflow 3: Processing
