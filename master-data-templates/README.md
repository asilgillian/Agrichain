# MTANDEO Master-Data Templates

Fill these CSVs **in order** — later files reference IDs from earlier ones by name.
All files are UTF-8, comma-separated, with the header row required.

## Recommended load order

| # | File | What it sets up | Depends on |
|---|------|------------------|------------|
| 1 | `01-admin-units.csv` | Country admin hierarchy (Region → District → Sub-county → Parish → Village) | — |
| 2 | `02-org-regions.csv` | MTANDEO's internal operational regions (clusters of districts) | 01 |
| 3 | `03-commodities.csv` | Master commodity catalog (Coffee, Maize, Cocoa…) | — |
| 4 | `04-commodity-types.csv` | Variant + processing stage per commodity (Robusta Cherry, Robusta Parchment…) | 03 |
| 5 | `05-commodity-prices.csv` | Opening price per type, per region | 04, 01 |
| 6 | `06-groups.csv` | Producer groups / cooperatives anchored to a village | 01 |
| 7 | `07-buying-stations.csv` | Field buying stations with optional GPS and manager | 10 (optional) |
| 8 | `08-silos.csv` | Warehouse silos for bulk commodities | — |
| 9 | `09-storage-bins.csv` | Warehouse bagged-stock bins | — |
| 10 | `10-users.csv` | Field agents and back-office staff | 02 (region), 06 (group) |

## Important notes

- **Uganda-localized defaults**: country code `UG`, currency `UGX`, phone format `+256XXXXXXXXX` (9 digits after +256).
- **IDs are generated by the system**. You reference parents by **name**, not by UUID — the import process will resolve them.
- **Status fields** default to `active`; leave blank unless you explicitly want `inactive` / `archived`.
- **Dates**: ISO format `YYYY-MM-DD`.
- **Users**: each user must sign in with Google/email *once* to get a `clerk_user_id`. The row in `10-users.csv` pre-creates the role + group assignment so they're not stuck on the Pending screen after first sign-in. Use the same email here as the one they'll sign in with.
- **Don't pre-load farmers / plots / deliveries** — those are transactional and are captured by field agents on the mobile app once master data exists.

## Importing

These CSVs are designed to be loaded via the admin web UI once the corresponding screens are open (Commodities, Admin Units, Groups, Users, etc.). If you'd like a one-shot batch importer, ask and I'll add a `pnpm` script that takes these files and POSTs through the API.
